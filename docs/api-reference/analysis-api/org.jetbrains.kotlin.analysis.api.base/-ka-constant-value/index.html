KaConstantValue

sealed interface KaConstantValue

Represents a compile-time constant value. It can be used as a const val initializer or as an annotation argument.

KaConstantValue can also represent evaluated values. For example, the constant expression 1 + 2 can be represented as an IntValue with a value 3.
