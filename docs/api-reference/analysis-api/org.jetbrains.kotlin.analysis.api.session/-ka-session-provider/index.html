KaSessionProvider

@SubclassOptInRequired(markerClass = [KaImplementationDetail::class])
abstract class KaSessionProvider(val project: Project) : Disposable

Provides KaSessions by use-site PsiElements or KaModules.

This provider should not be used directly. Please use analyze or analyzeCopy instead.
