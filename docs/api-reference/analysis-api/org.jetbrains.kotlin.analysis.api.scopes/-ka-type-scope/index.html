KaTypeScope

@SubclassOptInRequired(markerClass = [KaImplementationDetail::class])
interface KaTypeScope : KaScopeLike

A scope which contains members whose use-site type parameters have been substituted with the type arguments of a concrete KaType. Callable declarations with substituted type parameters are represented as KaCallableSignature.
