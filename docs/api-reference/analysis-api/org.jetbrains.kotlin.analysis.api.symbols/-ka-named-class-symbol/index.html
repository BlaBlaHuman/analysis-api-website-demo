KaNamedClassSymbol

@SubclassOptInRequired(markerClass = [KaImplementationDetail::class])
abstract class KaNamedClassSymbol : KaClassSymbol, KaNamedSymbol, KaContextReceiversOwner

KaNamedClassSymbol represents a named class, object, or interface declaration. The symbol covers most class declarations except for anonymous objects, which are represented by KaAnonymousObjectSymbol.
