KaSymbolProvider

@SubclassOptInRequired(markerClass = [KaSessionComponentImplementationDetail::class])
interface KaSymbolProvider : KaSessionComponent

KaSymbolProvider provides KaSymbols for given PSI elements.

Important: Symbols can be created only for elements which are a part of the current KaSession.
