KaSymbolOrigin

enum KaSymbolOrigin : Enum<KaSymbolOrigin>

KaSymbolOrigin describes the kind of data source (sources, libraries, etc.) or generation (SAM constructors, compiler plugins, etc.) the symbol originates from.

In cases where the origin is a generated declaration (e.g. SAM_CONSTRUCTOR, DELEGATED, JAVA_SYNTHETIC_PROPERTY), not only the generated declaration itself will have this origin, but all declarations contained in it as well. For example, while KaSamConstructorSymbol has a SAM_CONSTRUCTOR origin, its value parameters also share the same SAM_CONSTRUCTOR origin.
