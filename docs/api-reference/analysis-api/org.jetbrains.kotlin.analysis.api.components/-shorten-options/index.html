val removeContextSensitiveResolutionQualifiers: Boolean

If set to true, the reference shortener will detect removable qualifiers on references that rely on context-sensitive resolution (e.g., enum entries and sealed class subobjects that can be resolved without an explicit qualifier when the expected type is known from context).
