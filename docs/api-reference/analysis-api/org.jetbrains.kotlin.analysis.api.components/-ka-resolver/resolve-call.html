abstract fun KtArrayAccessExpression.resolveCall(): KaFunctionCall<KaNamedFunctionSymbol>?

Resolves the given KtArrayAccessExpression to a simple function call representing get/set operator invocation.

Example

class A {
    operator fun get(i: Int): Int = i
    operator fun set(i: Int, value: Int) {}
}

fun test(a: A) {
    a[0]
//  ^^^^  resolves to `get`
    a[0] = 1
//  ^^^^ resolves to `set`
}
Content copied to clipboard

Returns the corresponding KaSimpleFunctionCall if resolution succeeds; otherwise, it returns null (e.g., when unresolved or ambiguous).

This is a specialized counterpart of KtResolvableCall.resolveCall focused specifically on array access operations.

Note: the get call is prefered in the case of a compound assignent

fun test(m: MyMap<String, Int>) {
    m["a"] += 1
//  ^^^^^^
}

abstract fun KtForExpression.resolveCall(): KaForLoopCall?

Resolves the given KtForExpression to a KaForLoopCall representing the desugared for loop.

A for loop desugars into three operator calls:

  • iterator() on the loop range expression

  • hasNext() on the iterator

  • next() on the iterator

Example

for (item in list) {
    println(item)
}

Calling resolveCall() on the KtForExpression returns a KaForLoopCall containing the three desugared operator calls if resolution succeeds; otherwise, it returns null (e.g., when unresolved or ambiguous).
