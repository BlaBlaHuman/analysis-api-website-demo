KaScopeContext

@SubclassOptInRequired(markerClass = [KaImplementationDetail::class])
interface KaScopeContext : KaLifetimeOwner

A scope context includes all scopes that are relevant for a given KtElement position in a KtFile, together with all available implicit receivers.
