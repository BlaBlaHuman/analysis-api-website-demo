KaCallableSignature

sealed interface KaCallableSignature<out S : KaCallableSymbol> : KaLifetimeOwner

A use-site signature for a callable symbol. Compared to the symbol, the signature carries additional use-site type information.

The equality of KaCallableSignature is derived from its content.

Example

fun test(l: List<String>) {
  l.get(1)
}
Content copied to clipboard

The callable symbol for get has the type (Int) -> T where T is the type parameter declared in List. On the other hand, a KaCallableSignature for l.get carries the instantiated type information (Int) -> String.
